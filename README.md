# Pomodoro Study Timer

A productivity application built using React that helps users manage focused study sessions using the Pomodoro technique.

## Features

- Start, pause, resume, and reset timer
- Automatic focus and break sessions
- Session completion tracking
- Local storage support for persistence
- Responsive design for desktop and mobile devices
- Clean and modern user interface

## Technologies Used

- React
- JavaScript
- CSS
- Vite
